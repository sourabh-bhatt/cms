# Joint Tenancy: The Four Unities

<!-- When you're diving into the world of **joint tenancy**, it's essential to grasp the four critical elements, or **"unities,"** that must be present for it to be established. These are like the four pillars that hold up the structure of joint tenancy. Let's walk through each one so you can understand how they work together to create a joint tenancy. -->
Joint tenancy requires four critical elements, or **"unities,"** to be established. These four elements work together to create a joint tenancy.

## The Four Unities of Joint Tenancy

1. **Unity of Title**
   <!-- - This means that you and the other joint tenants must receive your ownership from the *same source*, whether it's the same deed or the same will.
   - Think of it like getting a group invitation; everyone has to be invited through the same message. -->
   - All joint tenants must receive ownership from the same source, whether the same deed or the same will.
   - Example: All parties receive ownership through the same deed transaction.

2. **Unity of Time**
   <!-- - Everyone named as joint tenants must receive their share at the *exact same moment*.
   - Imagine hitting play on a movie; if everyone doesn't start watching at the same time, someone's going to miss the beginning.
   - *Important:* If you want to add someone later, you must start over with a new deed because adding a new person later disrupts this synchronicity. -->
   - All joint tenants must receive their share at the same moment.
   - Example: All parties acquire ownership simultaneously through the same deed execution.
   - Note: Adding someone later requires creating a new deed because it disrupts this timing requirement.

3. **Unity of Interest**
   <!-- - All joint tenants own an *equal share* of the property.
   - Picture a pie divided into equal slices, where each person gets one slice.
   - No one can claim a bigger piece or a different duration of ownership; everyone shares equally in both size and time. -->
   - All joint tenants own an equal share of the property.
   - Example: Three joint tenants each own one-third interest in the property.
   - Each tenant has equal ownership rights for the same duration.

4. **Unity of Possession**
   <!-- - All joint tenants have *equal rights* to use the *entire property*, not just certain parts.
   - Imagine a shared house where everyone has the key to every room.
   - No one can lock a section off and claim it as their own; every tenant has the right to every part of the property. -->
   - All joint tenants have equal rights to use the entire property.
   - Example: Each tenant can access and use any part of the property.
   - No tenant can exclude others from any portion of the property.

## Why the Unities Matter

<!-- Understanding these unities is key because if *any one* of them is missing, what was intended to be a joint tenancy can instead become a **tenancy in common**, which changes how ownership and inheritance work. By keeping these unities in mind, you'll be better equipped to navigate the nuances of property rights and ownership in your journey. -->
These unities must all be present because if any one is missing, the intended joint tenancy becomes a **tenancy in common**, which changes ownership and inheritance rights.
